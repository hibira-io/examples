# Northwind Supply (Hibi demo shop)

A made-up shop admin for trying [Hibi for Chrome](https://github.com/hibira-io/browser-extension), and the page the Chrome Web Store reviewers use. It is one static page in seven languages (`?lang=` or the browser's language). Saved shipments stay in that browser's localStorage and nothing is sent anywhere. The ↺ link under the order list resets it.

Live: https://demos.hibira.io/examples/northwind/

Try it: open the page, turn Hibi on for demos.hibira.io, and type "Mark order #1042 shipped: DHL, tracking JD014600." Hibi fills in the shipment and waits for your approval before saving.
